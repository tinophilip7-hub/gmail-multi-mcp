Privacy policy: gmail-multi-mcp

Last updated: 1 October 2026

gmail-multi-mcp is a personal tool that runs on its owner's own computer. It is used only by its owner, to access the owner's own Google accounts. It is not offered to the public.

What data the app accesses

With the Google permission https://www.googleapis.com/auth/gmail.modify, the app can read, compose, send and organise (label, archive, mark as spam, move to trash) email in the Google accounts the owner connects. It cannot permanently delete email.

How the data is used

Email data is accessed only when the owner asks the AI assistant Claude to perform a task, such as searching, reading, drafting, sending or organising mail. The data is passed to Claude only as needed to complete that request. It is not used for advertising, it is not sold, and it is not used to build user profiles.

Where data is stored

  • The app has no server and no database. It runs on the owner's computer.
  • OAuth refresh tokens are stored in the macOS Keychain on that computer. They are never sent to the developer or any third party.
  • Email content is not stored by the app, except for attachments the owner explicitly asks to download, which are saved to a folder on the owner's computer.
  • The app does not log message contents, attachments or credentials.

Sharing

Data is not shared with anyone, apart from the AI assistant the owner uses with the app (Claude by Anthropic), and only to carry out the owner's own requests.

Google API Services User Data Policy

gmail-multi-mcp's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. The app's local data is deleted with its account:remove command.
